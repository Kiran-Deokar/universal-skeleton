universal-skeleton v1.2.0 — changed files only
==============================================

WHAT CHANGED
------------
Fix: shaped elements (badges, chips, pills with their own background colour)
now become ONE solid skeleton block instead of keeping their colour with only
the text inside skeletonised. While loading, the shape's background, border,
shadow and text are hidden (new .usk-s class), and the block inherits the
shape's own border-radius (rounded-full stays a pill).

Smart exceptions (nothing else regresses):
- decorative glows / overlays at low opacity (alpha < 0.35) are ignored
- tall coloured blocks like code blocks and callouts (> 64 px) keep the
  classic per-line text bars
- empty coloured leaves (dots, pills, spacers) are covered as one block too
- escape hatch unchanged: data-skeleton="text" forces per-line bars on a badge
