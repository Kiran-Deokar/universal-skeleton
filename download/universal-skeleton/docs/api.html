API reference

Everything universal-skeleton v1.1.0 exports. The same names apply whether you import the package, load the CDN bundle (global UniversalSkeleton), or use the Web Component.

SkeletonLoader

The programmatic facade. All methods accept an Element or a CSS selector string. Scanning the same target twice replaces the previous skeleton — handles are tracked per element, so nothing leaks.

SkeletonLoader.scan(target, options?)

Scans target, covers it with a skeleton overlay that mirrors the real geometry, and returns a handle. Throws if the selector matches nothing or the target is not an Element.

import { SkeletonLoader } from 'universal-skeleton';

const handle = SkeletonLoader.scan('#checkout', {
  effect: 'shimmer',     // animation (see Effects)
  theme: 'auto',         // light | dark | auto (see Themes)
  color: '#e5e7eb',      // base color — overrides the theme palette
  highlightColor: '#f3f4f6',
  duration: 1400,        // one cycle: ms number or CSS time like '2s'
  radius: 8,             // corner radius in px for rect blocks
  exclude: '.no-skeleton', // selector or (el) => boolean to skip subtrees
  textLines: true,       // one pill per estimated text line
  responsive: true,      // rebuild blocks on resize (ResizeObserver)
  blockInteraction: true,// block clicks + progress cursor while visible
});

// …later
handle.destroy();

OptionTypeDefaultDescription

theme'light' | 'dark' | 'auto''auto'Block color palette. auto follows prefers-color-scheme. Explicit color always wins.

textLinesbooleantrueWhen on, multi-line text becomes one pill bar per estimated line, with a shorter last line.

SkeletonLoader.while(source, target, options?)

Shows a skeleton on target while source runs, then destroys it automatically — including when the promise rejects. The resolved value passes through unchanged. Supports minDuration so fast responses do not flash.

const user = await SkeletonLoader.while(
  fetch('/api/user').then(r => r.json()),
  '#profile',
  { effect: 'pulse', minDuration: 600 },  // min on-screen time in ms
);

SkeletonLoader.restore(target)

Removes the active skeleton from target. Safe no-op when nothing is showing. Idempotent.

SkeletonLoader.isActive(target)

true while a skeleton is showing on target.

The handle returned by scan()

MemberDescription
handle.rootThe scanned element.
handle.overlayThe overlay <div class="usk-overlay …">.
handle.blocksNumber of skeleton blocks currently painted (getter).
handle.update()Re-measures the real UI and rebuilds every block — call after your data mutates the DOM.
handle.setEffect(name)Switch the animation at runtime. No rebuild; any of the 8 names, unknown falls back to shimmer.
handle.setTheme(name)Switch the palette at runtime — 'light' | 'dark' | 'auto'.
handle.destroy()Removes the overlay, restores the real UI, disconnects observers. Idempotent.

Effects

Eight built-in effects. The EFFECTS export lists them in display order — handy for building pickers.

NameLook
'shimmer'Moving gradient wave — the classic Facebook / YouTube skeleton (default).
'wave'Softer diagonal light sweep, larger gradient travel.
'pulse'Whole blocks fade in and out (Tailwind style).
'fade'Staggered breathing cascade — blocks light up one after another.
'blink'Hard steps() blink, terminal-cursor style.
'sheen'One glossy band sweeps across the whole overlay (blocks stay static).
'bounce'Gentle vertical bob, Material style.
'none'Static grey blocks, no animation.

All effects are pure CSS and honor prefers-reduced-motion: reduce (animation is disabled, blocks stay static).

Themes

The THEMES export lists ['light', 'dark', 'auto']. auto (the default) swaps palettes with a pure CSS media query — no JavaScript runs until you ask for it. Explicit color / highlightColor options and data-skeleton-color always beat the palette.

<skeleton-screen> Web Component

A zero-configuration custom element, registered automatically in the browser. Your real markup stays in the light DOM as children; the component overlays the skeleton while loading is truthy.

<skeleton-screen loading effect="shimmer" theme="light">
  <!-- your real markup, unchanged -->
</skeleton-screen>
AttributeValuesDescription
loadingpresent, or "true" | "1" | "on" | "loading"Show the skeleton. Remove it (or set "false") to reveal the content.
effectany of the 8 effect namesAnimation. Changing it re-syncs live.
themelight | dark | autoPalette. Changing it re-syncs live.
colorCSS colorBase block color.
highlight-colorCSS colorBand color for shimmer / wave / sheen.
durationCSS time or msOne animation cycle, e.g. "2s" or "800".
radiusnumber (px)Corner radius of rect blocks.

Methods: el.show(options?) and el.hide() for imperative control.

Manual mode — data attributes

Drop attributes on any element inside a scanned target to control how it is skeletonized.

AttributeDescription
data-skeleton="circle"Force a circular block covering the element.
data-skeleton="rect"Force one rounded rectangle covering the element (no recursion into children).
data-skeleton="text"Force per-line pill bars.
data-skeleton="none" / "ignore"Leave the element (and its subtree) out of the skeleton.
data-skeleton-ignoreBoolean equivalent of "ignore".
data-skeleton-radiusCorner radius override in px (e.g. "12").
data-skeleton-colorBase color override for this block.
data-skeleton-highlightHighlight color override for this block.

CSS variables

VariableDefaultDescription
--usk-color#e5e7ebBase grey of every skeleton block.
--usk-highlight#f3f4f6Bright band of shimmer / wave / sheen.
--usk-radius8pxCorner radius of rectangular blocks.
--usk-duration1.4sOne animation cycle.

Set them on :root for a global theme or on any container to scope it. The stylesheet is injected automatically and also shipped as dist/universal-skeleton.css (import universal-skeleton/css if you prefer shipping CSS yourself).

Accessibility

  • The scanned root gets aria-busy="true" while the skeleton shows; the previous value is restored on destroy.
  • The overlay is aria-hidden; with blockInteraction: true it traps pointer events and shows a progress cursor so users cannot click into the half-loaded UI.
  • prefers-reduced-motion disables every animation automatically.

SSR & Node

  • Importing the package in Node is safe — style injection and Web Component registration are guarded, so Next.js / Nuxt / Angular Universal server builds do not crash.
  • All DOM work happens when you call scan() / while() in browser code paths (effects, lifecycle hooks, event handlers).
  • The CDN bundle registers the global UniversalSkeleton and does nothing until you call it.
