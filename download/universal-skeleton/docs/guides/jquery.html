jQuery & legacy pages

Server-rendered pages, jQuery $.ajax flows, old SPA codebases — anywhere jQuery manipulates the DOM, the skeleton drops in with one script tag. No build step, no transpilation, ES5-friendly usage.

Install

<!-- before your own scripts -->
<script src="https://unpkg.com/universal-skeleton/dist/index.iife.min.js"></script>

This defines window.UniversalSkeleton. Everything below uses ES5 syntax on purpose, so it runs on the same browsers your legacy code targets (IE11 excluded — custom elements require a modern browser).

Skeleton around a jQuery Ajax call

var SkeletonLoader = window.UniversalSkeleton.SkeletonLoader;
var $list = $('#user-list');

function loadUsers() {
  SkeletonLoader.scan($list[0], { effect: 'shimmer', theme: 'light' });

  $.get('/api/users')
    .done(function (users) {
      renderUserRows($list, users);   // your existing render code
    })
    .fail(function () {
      showErrorBanner();
    })
    .always(function () {
      SkeletonLoader.restore($list[0]);
    });
}

Pass the raw DOM node ($list[0]) or a plain selector string ('#user-list') — both are accepted.

Promise-style with while()

SkeletonLoader.while(
  $.ajax({ url: '/api/orders', dataType: 'json' }).promise(),
  '#orders',
  { minDuration: 400, effect: 'pulse' }
).then(function (orders) {
  renderOrders(orders);
});

jQuery's .promise() is a real ES Promise in modern jQuery (2.1+), so it plugs straight in. On older stacks, use the scan/restore pattern above instead.

Skeleton on first page load

For server-rendered pages, mark regions that hydrate late with the Web Component — it works during HTML parsing, before any JS of yours runs:

<skeleton-screen loading effect="shimmer">
  <div id="dashboard">
    <!-- server-rendered content -->
  </div>
</skeleton-screen>

<script>
  $(function () {
    // after your init code finishes:
    $('skeleton-screen#dash').removeAttr('loading');
  });
</script>

Turbolinks / pjax / multi-page apps

  • Scan on page:before-fetch / before the pjax request starts.
  • Restore on the matching page:load / success event.
  • Because handles are per-element, a page navigation that swaps the body removes any overlay with it — no leaks.

Gotchas

  • Scan after the markup exists. Inside $(function () { … }) or right before an Ajax call — never at script top-level.
  • Scan the final geometry. If jQuery code hides/shows panels during init, finish those mutations first, then scan; or call handle.update() after they change.
  • IE11 and old Edge. Web Components features need modern browsers; on IE11 the CDN script itself loads but <skeleton-screen> will not upgrade. The scan() API also relies on WeakMap/ResizeObserver — for true legacy support ship a polyfill or stick to modern targets.
  • Multiple containers. One handle per element — loop over the jQuery set and scan each node:
$('.lazy-panel').each(function () {
  SkeletonLoader.scan(this, { effect: 'fade' });
});
